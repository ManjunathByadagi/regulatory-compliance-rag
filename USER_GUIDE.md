# User Guide

## Login

1. Open the assistant UI.
2. Sign in with assigned username and password.

## Ask Questions

- Use natural language: "What are CRAR requirements for UCBs?"
- Use exact terms for precision: "CRAR 9% RBI Circular 1452"
- Use comparison prompts: "Compare CRAR for commercial vs cooperative banks"

## Interpret Output

- Answer: primary result
- Confidence: green >= 80, yellow 60-79, red < 60
- Sources: document, section, page range, highlighted excerpts
- Review flag: verify with human reviewer if shown

## Filters

- Filter by document type and date range.
- Recent queries in sidebar show team activity.

## Best Practices

- For critical decisions, open cited PDF and verify highlighted excerpt.
- If answer says "I don't know", escalate to senior compliance review.
